# 📚 감정 6-3 즐겨찾기

학생 태블릿 활용 수업을 위한 링크 모음 페이지입니다.
학생들은 홈 화면에 추가된 아이콘으로 접속하고, 교사는 링크만 수정하면 됩니다.

## 🔗 링크 수정 방법

이제 **`index.html`은 건드릴 필요 없이 `links.json` 파일 하나만 수정**하면 됩니다.
GitHub 웹사이트(또는 GitHub 모바일 앱)에서 `links.json` → 연필 아이콘(Edit) → 수정 → Commit 하면 끝.

```json
{
  "updated": "2026-09-04",        ← 수정한 날짜 (페이지 상단에 표시됨)
  "notice": "",                    ← 공지사항. 내용을 적으면 노란 배너로 표시, 비우면 숨김
  "links": [
    {
      "name": "카훗",              ← 버튼에 표시될 이름
      "url": "https://kahoot.it",  ← 이동할 주소
      "emoji": "🎯",               ← 카드에 표시될 이모지
      "isNew": false,              ← true로 하면 NEW 배지가 붙음
      "featured": false            ← true로 하면 맨 위에 "⭐ 오늘의 링크"로 크게 표시됨
    }
  ]
}
```

> ⚠️ 마지막 항목 뒤에는 쉼표(,)를 붙이지 않도록 주의하세요. (JSON 문법 오류가 나면 페이지가 예전 목록을 보여줍니다)

### 수업 시작 전 활용 팁
- 오늘 수업에서 쓸 링크에 `"featured": true`를 켜두면 학생들이 들어오자마자 맨 위 큰 카드를 눌러 바로 이동합니다.
- 새로 추가한 링크는 `"isNew": true`로 NEW 배지를 붙여 눈에 띄게 하세요.

## 🔄 캐시(새로고침) 문제 해결됨

- 링크 목록(`links.json`)은 **접속할 때마다 서버에서 새로 ** 받아옵니다 (브라우저 캐시 완전 우회).
- 학생이 홈 화면 아이콘으로 페이지를 **다시 열거나 탭으로 돌아올 때마다 자동으로 최신 목록으로 갱신**됩니다.
- 인터넷이 잠깐 끊겨도 마지막으로 본 목록을 보여줍니다.
- GitHub Pages는 반영에 최대 1~2분 정도 걸릴 수 있습니다 (커밋 직후 잠깐 기다리세요).

## 🔔 알림(푸시) 보내는 방법

OneSignal 무료 웹 푸시가 연동되어 있습니다.

1. **학생 쪽 (1회만)**: 페이지에 접속하면 상단에 「🔔 알림 켜기」 버튼이 보입니다. 눌러서 알림을 허용하면 등록 완료. (수업 시간에 한 번 전체 안내로 눌러 두게 하세요)
2. **교사 쪽**: [OneSignal 대시보드](https://dashboard.onesignal.com) → 해당 앱 선택 → **Messages → New Push** → 제목/내용 입력 → Send. 학생 태블릿에 알림이 도착하고, 누르면 이 페이지가 열립니다.

지원 환경: 안드로이드 태블릿의 **크롬 / 삼성 인터넷 모두 지원**됩니다. (iPad는 홈 화면 추가 후에만 가능)

## 📁 파일 구성

| 파일 | 역할 |
|---|---|
| `links.json` | **링크 목록 + 공지 (교사가 수정하는 유일한 파일)** |
| `index.html` | 페이지 디자인과 동작 |
| `sw.js` | 서비스 워커 (오프라인 대비 + 푸시 알림 수신) |
| `OneSignalSDKWorker.js` | 예전 기기 호환용 (sw.js를 불러오기만 함) |
| `manifest.json` | 홈 화면 추가 시 아이콘/이름 설정 |
